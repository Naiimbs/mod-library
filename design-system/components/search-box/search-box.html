Search Box

A dedicated search field with a leading search icon, a clear action that appears while typing, the library's bottom press line on focus, and error, read-only, and disabled states. Ported from the DGA library's dga-search-box component.

Props / Configuration

All available CSS classes for configuring search boxes, mapped from the library's dga-search-box API.

Class Type Library prop Description
.search-box Base — 40px field with a gray-400 border; hover darkens it to gray-700.
.search-box.focus / .active State — Focus grows the bottom press line to full width; active (pressed) shows 50%.
.search-box--error State error Error border and press line, usually with the error feedback icon.
.search-box--readonly / --disabled State readonly, disabled Muted field without the press line; disabled also mutes the icons.
.search-box__icon / .search-box__field Element placeholder Leading 20px search icon and the borderless input.
.search-box__actions / __action-btn / __divider Element — Trailing actions (clear, optional search button) separated by a 1px divider. The page script shows them only while the field has text.
.search-box__feedback-icon--success|--error|--warning Element feedback Status icon with a soft tinted halo before the actions.

Default

Type in the field: the clear action appears with its divider, and clearing refocuses the input.

Validation & States

Error recolors the border and press line; success shows the tinted check; read-only and disabled mute the field.

RTL Layout

The icon leads from the right and the actions trail on the left.
