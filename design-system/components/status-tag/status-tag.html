Status Tag

Pill-shaped indicators that surface the state of an item with a colored dot and a short label. Five semantic variants (Neutral, Info, Success, Warning, Error), three sizes (Medium, Small, X-Small), and three styles (Subtle, Inverted, Ghost). Modeled on the Figma source frame 5698:52957.

Live demo

Status Tag

A status tag pairs a colored dot with a short label to communicate the current state of an item — for example, a record's review status or a workflow stage.

This live demo contains only a preview of functionality and styles available for this component.

Props / Configuration

All available CSS classes for configuring status tag components.

Class Type Default Description
.status-tag CSS class Required Base status-tag class. Must be applied to all status tags.
.status-tag__dot CSS class Required Colored dot indicator. Place as the first child of the tag.
.status-tag__label CSS class Required Status label text. Place as the second child of the tag.
.status-tag--neutral CSS class Default variant Gray variant for unset or default states. Applied implicitly when no other variant is present.
.status-tag--info CSS class — Blue variant for informational states.
.status-tag--success CSS class — Green variant for positive or completed states.
.status-tag--warning CSS class — Amber variant for cautionary states.
.status-tag--error CSS class — Red variant for errors or destructive states.
.status-tag--subtle CSS class — Light tinted background with colored text and dot.
.status-tag--inverted CSS class — Solid colored background with white text and a translucent white dot.
.status-tag--ghost CSS class — Transparent background showing only the colored dot and label.
.status-tag--md CSS class Default size Medium size (32px height, 16px / 24px text). Default when no size class is applied.
.status-tag--sm CSS class — Small size (24px height, 14px / 20px text).
.status-tag--xs CSS class — X-Small size (20px height, 10px / 14px text). Dot shrinks from 8px to 6px.

Variants

The five semantic variants shown in the default Subtle style. Variant choice communicates meaning — Neutral for unset, Info for information, Success for positive states, Warning for caution, Error for failure.

Neutral Info Success Warning Error

Sizes

Three sizes matching the Figma typography scale. Medium (32px, 16/24 medium), Small (24px, 14/20 medium), and X-Small (20px, 10/14 medium — dot shrinks from 8px to 6px).

Medium (32px) Small (24px) X-Small (20px)

Subtle Style

Light tinted background paired with darker colored text. The default presentation — quiet enough to use anywhere in dense UIs while still carrying semantic color.
