Progress Bar

Progress bars communicate how much of a process has completed. The linear bar comes in three heights and four styles with an optional label and helper note; the circular bar comes in five diameters with a percentage or state icon at its center. Ported from the DGA library's dga-linear-progress-bar and dga-circular-progress-bar components.

Live demo

Progress Bar

Use the linear bar inside forms and cards, and the circular bar for dashboards and confirmations.

This live demo contains only a preview of functionality and styles available for this component. The large linear bar shows its percentage inside the fill once it passes 8%.

Props / Configuration

All available CSS classes and data attributes, mapped from the library's dga-linear-progress-bar and dga-circular-progress-bar APIs.

Class / Attribute Type Library prop Description
.progress-wrapper Base (linear) — Column layout holding the label, the track, and the helper note.
.progress-bar-container.sm|.md|.lg Modifier size Track heights 4 / 8 / 16px. The large size rounds to 8px radius and can show the value inside the fill.
.progress-bar.primary|.neutral|.error|.success Modifier progress-style, error, success Fill color. Width is set inline as a percentage; it animates over 0.5s.
.progress-bar__label / .progress-bar__note Element label, helper-text Optional label above and icon + note below. The note tone follows error/success.
.circular-progress-bar Base (circular) — Declarative: set data-size, data-percentage, data-variant, data-text and the page script renders the SVG ring (stroke = diameter / 10).
data-size="200|160|120|80|64" Attribute size Ring diameter. Center typography and icon scale per size; the text label hides at 80 and 64.
data-variant="primary|neutral|error|success" Attribute variant Ring color. Success and error swap the center percentage for a state icon.

Circular Sizes

Five diameters with a stroke of one tenth of the size. The center percentage scales with the ring; the optional text label hides at 80px and below.

Circular Variants

Primary and neutral rings show the running percentage; success and error complete the ring and swap the center for a state icon.

RTL Layout

In right-to-left layouts the linear fill anchors to the right edge and the note mirrors.
