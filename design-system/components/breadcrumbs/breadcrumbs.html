Breadcrumb

A navigation aid that shows the current page's position within the site hierarchy and lets users backtrack to ancestor pages. Links use the neutral link color; the current page is a muted, non-interactive label; and a chevron separates each level. When the trail gets long it collapses the middle into an overflow (…) that opens a dropdown of the hidden links. Full RTL support. Modeled on Figma frames 5698:2597 (Breadcrumb) and 5698:2585 (Breadcrumb Item).

With overflow on and 4+ levels, the middle links collapse behind a … toggle — click it to reveal the hidden links in a dropdown (reusing the Menu component). Click outside or press Esc to close.

Props / Configuration

Classes for composing a breadcrumb trail.

Class / Attribute Type Description
.breadcrumbContainerThe <nav> trail. Use aria-label="Breadcrumb". 14/20 regular text.
.breadcrumb-itemItemWraps a link, the current label, or the overflow toggle.
.breadcrumb-linkLinkAncestor link — neutral color (#384250), underlines on hover.
.breadcrumb-currentLabelThe current page — muted (#9DA4AE), non-interactive. Pair with aria-current="page".
.breadcrumb-separatorSlotChevron between items (#9DA4AE). Auto-flips in RTL. Mark aria-hidden="true".
.breadcrumb-overflowItemCollapsed-middle item holding the … toggle and a .menu dropdown of hidden links.
.breadcrumb-overflow__toggleTriggerThe … button that opens the overflow dropdown (outside-click / ESC close).
