Nav Header

The UI-shell navigation header that guides users through a site. It appears at the top of every page and holds the platform logo, primary menu items (with optional sub-menu dropdowns), and action buttons. Adapts across desktop (>960), tablet (600–960), and mobile (<600) breakpoints, supports contained or full-width layouts, and mirrors fully for RTL. Modeled on Figma frames 30150:148751 (Nav Header), 148312 (Menu Item), 148445 (Action), 148860 (Menu), 148877 (Sub-menu), 148183 (Sub-menu Item), 148742 (Item Icon).

Props / Configuration

The classes and JS hooks that compose the navigation header.

Class / Attribute Type Description
.navigation-headerContainer72px-tall header bar with a left section (logo + menu) and right section (actions).
.logo-placeholderSlotPlatform logo + label at the leading edge.
.navigation-menuSlotThe primary menu bar holding .header-menu-item links.
.header-menu-itemItemA menu link. Add --selected for the active state, --disabled to disable, and data-submenu="ID" to attach a dropdown.
.header-actionItemAction button. Variants: --outline, --primary, --icon-only. Plus --selected / --disabled states.
.header-sub-menuDropdownPanel opened by a menu item. Add .is-open to show, --full for a mega-menu, --brand for the green panel.
.header-sub-menu-group / __labelSlotA column of sub-menu items with an optional group label.
.header-sub-menu-itemItemIcon + label + optional helper text link inside the dropdown.
.header-menu-toggleTriggerHamburger button shown on tablet/mobile breakpoints.
data-submenu="ID"JS hookOn a menu item — toggles the .header-sub-menu with that id (click outside / ESC closes).

Menu Item

States per Figma 30150:148312. Default, hover (gray fill + gray indicator pill), selected (green fill + light-green indicator), and disabled. Each item can carry a dropdown chevron.
