Inline Alert

Inline alerts surface page-level messages in the flow of content. Five semantic types (neutral, info, error, warning, success) with an accent edge, an optional colored background, an optional dismiss button, and optional action buttons. Ported from the DGA library's dga-inline-alert component.

Live demo

Inline Alert

Alerts communicate a state that affects the page or a section of it. Use the type that matches the severity of the message.

This live demo contains only a preview of functionality and styles available for this component. Dismissing the alert with its close button re-renders it when any control changes.

Props / Configuration

All available CSS classes for configuring inline alerts, mapped from the library's dga-inline-alert API.

Class Type Library prop Description
.inline-alert Base — Root container. Full-width, accent edge on the reading side.
.inline-alert--neutral / --info / --error / --warning / --success Modifier type Semantic type. Sets the accent edge and the featured icon colors.
.inline-alert--{type}-bg Modifier colored Colored background variant: 25-tint background with a 200-tint border.
.inline-alert__header Element — Icon + text + close row. Add --centered when there is no helper text.
.inline-alert__icon Element — 40px featured icon circle, tinted by the alert type.
.inline-alert__title Element lead-text Alert heading. Pair with .text-md-semibold.
.inline-alert__content Element helper-text Optional supporting copy. Pair with .text-sm-regular.
.inline-alert__close Element is-close-button Dismiss slot. Contains a transparent icon-only design-system button.
.inline-alert__action / .inline-alert__action-mobile Element isaction-buttons, buttons-list Action row using design-system buttons. The mobile variant stacks full-width under 600px.

Types

Five semantic types. The accent edge and the featured icon communicate severity; the layout stays identical.

Neutral alert

A general message that does not carry a semantic state.

Info alert

Something the user should know before they continue.

Success alert

The request was submitted successfully.

Warning alert

Review the highlighted fields before submitting.

Error alert

The request could not be completed. Try again later.

Colored Background

The colored variant fills the alert with the type's 25-tint and softens the border to the 200-tint.

With Action Buttons

Alerts can carry actions, indented to align with the text column. Under 600px the actions stack full-width below the message.
