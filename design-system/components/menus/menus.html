Menu

A floating list of actions or options, opened from a trigger (button, icon, or nav item) or used as a context menu. Items can group under labels, carry a leading icon, and show a trailing element (count text, icon, tag, or switch). Six item states — default, hover, pressed, selected, focused, disabled — plus full RTL. Modeled on Figma frames 30195:22214 (Menu) and 30195:21865 (Menu list item).

Props / Configuration

Classes and JS hooks for composing menus.

Class / Attribute Type Description
.menuContainerThe popover: white bg, neutral-primary border, 8px radius, shadow-2xl, 8px padding.
.menu-groupSlotA group of items. Adjacent groups are separated by a top divider. Add data-menu-select for single-select behavior.
.menu-group__labelSlotUppercase group heading (12/18 bold, text-display).
.menu-dividerSlotStandalone 1px divider between items.
.menu-itemItem40px row: leading icon + label + optional trailing slot. States via --selected / --disabled, plus :hover / :active / :focus-visible.
.menu-item__iconSlot16px leading icon glyph.
.menu-item__labelSlotItem text (16/24 regular). Fills the row and ellipsizes on overflow.
.menu-item__trail / --textSlotTrailing element wrapper. --text styles a small count/label (#6C737F).
.menu-item__trail-iconSlotTrailing icon (20px) — e.g. a check for selected or an arrow for submenu.
.menu-switchControlTrailing toggle. Add .is-on for the checked (#0D121C) state.
data-menu-trigger="ID"JS hookOn a trigger — opens the .menu inside a .menu-anchor with that id. Outside-click / ESC close.

RTL Support

Arabic and other right-to-left layouts mirror the menu: the leading icon moves to the right, the label aligns right, and trailing elements move to the left.
