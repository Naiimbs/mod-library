Tags

Compact, non-interactive labels used to attach metadata, categorize content, or surface status. Tags come in five semantic variants plus an On-Color variant for dark surfaces, three sizes, and support filled and outlined styles, rounded (pill) shape, leading and trailing icon slots, and icon-only forms.

Tag

Tags are short, non-interactive labels. Use them to mark items with a category, a status, or a piece of metadata that a reader can scan at a glance.

This live demo contains only a preview of functionality and styles available for this component. Selecting the On-Color variant darkens the preview canvas so the white-on-alpha styling has its intended backdrop.

Props / Configuration

All available CSS classes for configuring tag components.

Class Type Default Description
.tag CSS class Required Base tag class. Must be applied to all tags.
.tag--neutral CSS class Default variant Gray neutral variant. Applied implicitly when no other variant class is present.
.tag--success CSS class — Green variant for positive or completed states.
.tag--error CSS class — Red variant for errors or destructive states.
.tag--warning CSS class — Yellow/amber variant for cautionary states.
.tag--info CSS class — Blue variant for informational states.
.tag--on-color CSS class — White-on-alpha variant for use on dark or colored backgrounds.
.tag--md CSS class — Medium size (32px height, 16px / 24px text).
.tag--sm CSS class Default size Small size (24px height, 12px / 18px text). Default when no size class is applied.
.tag--xs CSS class — X-Small size (20px height, 10px / 14px semibold text).
.tag--outline CSS class — Transparent fill with colored border. Combines with any variant.
.tag--rounded CSS class — Pill shape with fully rounded corners.
.tag--icon-only CSS class — Square tag containing only an icon (no label).
.tag__icon CSS class — Icon slot. Use one before the label for a leading icon, one after for a trailing icon, or both.

Tag Variants

The five semantic variants. Neutral for default metadata, Success and Error for positive and negative states, Warning and Info for cautionary and informational signals. The On-Color variant is shown separately below.

Neutral Success Error Warning Info

Tag Sizes

Three size options matching the Figma typography scale. Medium (32px, 16/24 medium), Small (24px, 12/18 medium — the default), and X-Small (20px, 10/14 semibold).

Medium (32px) Small (24px) X-Small (20px)

Outline Variants

Outlined style strips the fill, keeping only the border and label color. Use when a softer visual weight is needed, such as in dense lists or alongside other UI controls.

Rounded Variants

Pill-shaped tags use a fully rounded border-radius. Available across all variants and combinable with the outline modifier.

Square tags containing only an icon (no label). Useful for compact status indicators in tables and lists. Available across all three sizes and combinable with any variant or shape.

On-Color Variant

For use on dark or colored backgrounds. Uses white at 20% alpha for the fill, white at 60% alpha for the border, and pure white for the label and icon — matching the Figma tag-background-on-color and tag-border-on-color tokens.
