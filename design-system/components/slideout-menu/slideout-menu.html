Slideout Menu

A panel that slides in from the side of the screen, triggered by a button. It surfaces navigation, options, or extra content without cluttering the main view. Composed of a header (featured icon + title + description + close), a scrollable body (a menu-items list or a custom content slot), and an actions footer. Anchors left or right, ships gray or white, and mirrors fully for RTL. Modeled on Figma frames 23360:17219 (Slideout Menu) and 23521:31454 (Slideout Menu Header); the body reuses the Menu component.

Props / Configuration

Classes and JS hooks for composing and triggering a slideout.

Class / Attribute Type Description
.slideout-backdropOverlayDimmed full-screen overlay. Add .is-open to show.
.slideoutPanel346px side panel, fixed full-height, slides in via transform. .is-open reveals it.
.slideout--rightModifierAnchor the panel to the right edge (default is left / leading).
.slideout--grayModifierUse the gray background (#F9FAFB) instead of white.
.slideout--inlineModifierRender the panel in normal flow (used by the docs previews) instead of fixed/sliding.
.slideout__headerSlotFeatured icon + title + description + close button.
.slideout__bodySlotScrollable content area. Hosts a .menu (groups/items) or a .slideout-custom slot.
.slideout__footerSlotAction buttons row (equal-width).
data-slideout-open="ID"JS hookOn a trigger — opens the panel with that id over its backdrop.
data-slideout-closeJS hookOn any element inside the panel — closes it. Backdrop click and ESC also close.
