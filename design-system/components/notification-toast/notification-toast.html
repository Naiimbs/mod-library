Notification Toast

Notifications are peripheral messages in digital products that communicate information or feedback to the user. These are transient, non-modal messages that appear at the top of the screen to provide brief alerts, disappearing after a set duration.

Configure the toast appearance and features.

Props

Prop Type Default Description
type 'neutral' | 'info' | 'critical' | 'warning' | 'success' 'neutral' Visual style variant of the toast notification.
lead-text string --- Bold title text displayed prominently.
helper-text string --- Supporting description text below the title.
has-helper-text boolean false Show or hide the helper/description text.
action boolean false Show action buttons.
close-button boolean true Show the close/dismiss button.
v-position 'top' | 'bottom' 'top' Vertical position on the screen.
h-position 'left' | 'right' 'right' Horizontal position on the screen.
