Textarea

A text area enables users to input and edit multiple lines of text, providing a larger space than a regular text input field, making it suitable for longer text entries such as comments, descriptions, or messages.

Live demo

Textarea

A multi-line text input for longer form content like comments, descriptions, or messages.

Props

Prop Type Default Description
label string — Label text displayed above the textarea.
placeholder string — Placeholder text shown when the field is empty.
variant 'default' | 'lighter' | 'darker' 'default' Visual style variant controlling background color.
value string '' Current value of the textarea.
disabled boolean false Prevents user interaction.
readonly boolean false Makes the content non-editable but copyable.
error boolean false Applies error styling (red border).
required boolean false Marks the field as required (asterisk on label).
resize boolean true Enables vertical resizing of the textarea.
rows number 4 Number of visible text lines.
cols number 50 Visible width of the textarea in character widths.
helper-text string — Descriptive hint text displayed below the field.

States

All interactive states of the textarea component — default, filled, disabled, read-only, and focus (click to see).
