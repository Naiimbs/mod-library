Accordion

Accordions collapse long content into scannable sections that expand on demand. Three sizes, a leading or trailing chevron, a flush variant with inset separators, and disabled items. Ported from the DGA library's nds-accordion component.

Live demo

Accordion

Click a header to expand its content. The body animates to its measured height, exactly like the library behavior.

This live demo contains only a preview of functionality and styles available for this component. Changing a control re-renders the accordion collapsed.

Props / Configuration

All available CSS classes for configuring accordions, mapped from the library's nds-accordion API.

Class Type Library prop Description
.accordion Base — List container (<ul>). Draws the bottom border of the last item.
.accordion-item Base — One section: a header button plus a collapsible body, separated by top borders.
.accordion-item--lg|--md|--sm Modifier size Header padding density: 16px / 12×16px / 8×16px.
.accordion-item--icon-leading Modifier icon-alignment Moves the chevron before the title and indents the body under it. Default is trailing.
.accordion-item--flush Modifier flush Replaces full-width borders with an inset separator that stops 16px from each edge.
.accordion-item.active State is-open Expanded: the chevron rotates 180° and the body animates to its measured height.
.accordion-item.disabled State disabled Grays the item out and ignores interaction.
.accordion-item__header / __title / __arrow / __body Element title, content Header is a real <button> with aria-expanded; the title is 16px semibold, the body 16px regular.
