Progress Indicator

Progress Indicator enables incremental navigation through a series of steps or stages in a process. It provides clear visual cues indicating the current step to help users understand their progress.

Live demo

Progress Indicator

Facilitates step-by-step navigation through a process or sequence, commonly used in forms or multi-step processes.

Adjust controls to explore different Progress Indicator configurations. Each step shows Completed, Current, or Upcoming state automatically.

Props

Prop Type Default Description
active-step number — Index of the currently active step (1-based)
alignment "horizontal" | "vertical" "horizontal" Layout direction of the progress indicator
show-step-name boolean true Whether to display the step title text
show-step-description boolean true Whether to display the step description text
RTL boolean false Right-to-left layout direction

Step Child Props

Prop Type Default Description
title string — Step title text
description string — Step description text
status "completed" | "current" | "upcoming" — Visual state of the step (derived from active-step)
