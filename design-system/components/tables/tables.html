Tables

Structured rows and columns for displaying and interacting with data. Includes sortable and filterable header cells, row selection (with select-all + indeterminate state), six body cell types (text, link, status, tag, action, checkbox), striped and bordered variants, three densities, and full RTL support. Modeled on Figma frames 5698:40875 (Table), 5898:27389 (Header), 5698:40844 (Row).

Props / Configuration

All available CSS classes for composing tables.

Class Type Description
.table-wrapperCSS classContainer providing the rounded outer border and horizontal scroll on overflow.
.tableCSS classApplied to the <table> element. Sets typography, collapse mode, and base spacing.
.table--compactCSS classTighter cell padding (4px × 12px) for dense layouts.
.table--relaxedCSS classRoomier cell padding (16px × 24px).
.table--stripedCSS classAlternate row background tint.
.table--borderedCSS classAdds vertical borders between columns in addition to the row dividers.
.table__cell--linkCSS class on <td>Link-styled cell (Saudi green text, underline on hover).
.table__cell--textCSS class on <td>Plain body text cell. Default styling — class is optional and exists for clarity.
.table__cell--actionCSS class on <td>/<th>Narrow column holding a single icon button.
.table__cell--checkboxCSS class on <td>/<th>Narrow leading column for the selection checkbox.
.table__checkboxCSS class on <input type="checkbox">Styled checkbox used for both select-all and per-row selection. Supports :indeterminate.
.table__sortCSS class on <button> inside <th>Sortable header. Set data-sort="asc" or "desc" to display the active arrow.
.table__sort-iconCSS classDecorative element rendering the up/down arrows. Place inside .table__sort.
.table__filterCSS class on <button>Filter button (funnel icon). Use aria-pressed="true" for the active/filtered state.
.table__actionCSS class on <button>Generic icon button used in row action cells. Arrow auto-flips in RTL.
.is-selected / aria-selected="true"State on <tr>Highlights a selected row using the primary-light token.
