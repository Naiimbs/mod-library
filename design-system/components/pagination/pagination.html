Pagination

Horizontal navigation between chunks (pages) of a dataset. Shows the first and last page plus the current page and a configurable number of sibling pages on each side, collapsing the rest into ellipses. Includes previous/next controls (disabled at the bounds), three sizes, optional text labels, and full RTL support. Modeled on Figma frames 7936:8133 (Pagination) and 7936:16660 (Pagination Item).

Live demo

Pagination

Click pages or prev/next to navigate. Adjust total pages and sibling count to see the ellipsis truncation respond.

The sequence always keeps the first and last page visible. With a high total page count, only the current page ± the sibling count stay expanded; everything else collapses to "…".

Props / Configuration

Classes and the JS API for the pagination component.

Class / API Type Description
.paginationContainerThe <nav> wrapper. Add --sm / --lg to change size.
.pagination-itemItemA page number or prev/next control. 40px square (md), borderless, rounded.
.pagination-item.is-activeStateThe current page — filled with the primary token, white text. Pair with aria-current="page".
.pagination-item.is-disabledStateDisabled prev/next at the first/last page.
.pagination-item--navModifierMarks a prev/next control (holds the arrow icon and optional label).
.pagination-ellipsisItemNon-interactive "…" gap marker.
paginationRange(total, current, siblings)JS fnReturns the token sequence (page numbers + "…") to render, per the DgaPagination algorithm.
PaginationDemoManagerJS classRenders a dynamic, navigable pagination driven by total page count, current page, and sibling count.
