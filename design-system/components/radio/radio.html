Radio Button

A radio button lets users choose one option from a group of options. When they pick one, any previously selected option is deselected. Radio buttons are commonly used in forms and surveys when users need to pick just one choice from a list.

Radio Button

Select a single option from a group. Only one option can be active at a time.

Props

Prop Type Default Description
label string — Label text displayed next to the radio button.
name string — Groups radio buttons so only one can be selected at a time.
value string — The value submitted when this radio is selected.
checked boolean false Whether the radio button is selected.
disabled boolean false Prevents user interaction.
style 'primary' | 'neutral' 'primary' Visual style — primary (green dot) or neutral (black dot).
helper-text string — Descriptive text displayed below the label.
alert-message string — Error or warning message with icon.
