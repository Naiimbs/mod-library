Checkbox

A checkbox allows users to make a single selection or indicate a binary choice. Checkboxes enable users to interact with options within an interface. They can be toggled individually for specific selections or grouped together to allow multiple choices.

Props

Prop Type Default Description
label string — Label text displayed next to the checkbox.
name string — Groups checkboxes for form submission.
value string — The value submitted when this checkbox is checked.
checked boolean false Whether the checkbox is selected.
indeterminate boolean false Shows a partial selection state (minus icon). Set via JavaScript.
disabled boolean false Prevents user interaction.
style 'primary' | 'neutral' 'primary' Visual style — primary (green fill) or neutral (black fill).
size 'md' | 'sm' | 'xs' 'md' Hitbox size — medium (24px), small (20px), or x-small (16px).
helper-text string — Descriptive text displayed below the label.
alert-message string — Error or warning message with icon.
