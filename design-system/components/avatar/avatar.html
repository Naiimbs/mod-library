Avatar

Avatars represent a person or entity as an image, initials, or an icon. Seven sizes, circular or square shape, an optional inner border ring, and avatar groups with spaced or stacked layouts. Ported from the DGA library's nds-avatar and dga-avatar-group components.

Live demo

Avatar

Use the image type when a photo exists, initials as the fallback, and the icon type for anonymous or system entities.

This live demo contains only a preview of functionality and styles available for this component. Enabling Stacked group also enables Group.

Props / Configuration

All available CSS classes for configuring avatars, mapped from the library's nds-avatar and dga-avatar-group APIs.

Class Type Library prop Description
.avatar Base — Circular container with a white outer border and neutral background.
.avatar--image / --text / --icon Modifier type Content type: a cover-fitted <img>, uppercase initials, or an icon glyph.
.avatar--120 … .avatar--24 Modifier size Seven sizes: 120, 80, 68, 48, 40, 32, 24. Each pairs its own text and icon scale; 120 uses a 4px outer border.
.avatar--square Modifier square Rounded square (8px radius) instead of a circle.
.avatar--border Modifier border Adds a subtle 1px inner ring (20% black) for avatars on light imagery.
.avatar__text / .avatar__icon Element — Initials label / icon glyph, auto-scaled by the size modifier.
.avatar-group Base — Row of avatars with a 4px gap.
.avatar-group--stacked Modifier stacked Overlapping layout (-10px), RTL-aware.
.avatar-group__more Element — "+N" overflow counter avatar at the end of a group.

Sizes

Seven sizes from 120px to 24px. Initials and icons scale with the container; the 120 size thickens its outer border to 4px.

Types

The square modifier switches to an 8px radius. The border modifier adds a subtle inner ring that keeps light photos separated from light backgrounds.

Groups lay avatars in a row with a 4px gap, or stack them with a -10px overlap. End the group with a "+N" counter for overflow.
