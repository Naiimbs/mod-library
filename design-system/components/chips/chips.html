Chips

Chips are small, interactive elements used to display information, trigger actions, or allow selections. Available in 2 styles, 3 sizes, with rounded, on-color, and selected variants.

Live demo

Chip

Chips are compact elements that represent an input, attribute, or action. They allow users to make selections, filter content, or trigger actions.

This live demo contains only a preview of functionality and styles available for this component.

Props / Configuration

All available CSS classes and HTML attributes for configuring chip components.

Class / Attribute Type Default Description
.chip CSS class Required Base chip class. Must be applied to all chips.
.chip-primary CSS class — Primary brand-colored chip style with green tones.
.chip-neutral CSS class — Neutral gray chip style for general-purpose use.
.chip-medium CSS class — Medium size (24px height).
.chip-small CSS class — Small size (20px height).
.chip-rounded CSS class — Applies full pill/rounded shape to the chip.
.selected CSS class — Visual selected state. Changes to filled background.
.chip-on-color CSS class — Modifier for dark/colored backgrounds. Inverts chip colors for contrast.
.chip-icon-only CSS class — Square chip containing only an icon (no label text).
disabled HTML attr false Disables the chip. Grays out appearance and prevents interaction.
aria-pressed HTML attr — Set to "true" for chips in selected state.

Chip Styles

The two core chip styles. Primary for brand-colored selections and Neutral for general-purpose use.

Three size options to fit different contexts. Large (32px) is the default, Medium (24px) for denser layouts, and Small (20px) for compact usage.
