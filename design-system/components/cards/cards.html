Cards

Surface containers for grouping related content with a featured icon, title, body copy, and optional action footer. Three effect styles (With Shadow, No Shadow, Stroke), three states (Default, Selected, Disabled), three card types (Default, Expandable, Selectable), and full RTL support. Modeled on Figma frame 30195:10358.

Live demo

Card

Cards group a featured icon, headline, body text, and actions into a tappable surface. Use the controls to explore every supported state.

State "Selected" only takes visible effect on the Selectable card type. The Expanded toggle only applies to the Expandable card type. Click an Expandable card or its bottom-right chevron to toggle state in the preview.

Props / Configuration

All available CSS classes for composing cards.

Class Type Description
.cardCSS classBase card class. Sets layout, padding, background, radius, and default shadow.
.card-iconCSS class48×48 circular icon slot using the brand-light background and primary icon color.
.card-contentCSS classVertical stack for the title and body copy.
.card-titleCSS classDisplay heading inside the card. 18/28 bold (Figma text-lg/Bold).
.card-bodyCSS classBody copy. 16/24 regular (Figma text-md/Regular).
.card-footerCSS classHorizontal action row at the bottom of the card. Hosts .btn elements.
.card-imageCSS classImage slot sitting inside the card's padding. 4:3 aspect ratio, radius-md rounded corners. The featured icon, when present, renders as a separate sibling below the image (leading-edge aligned).
.card-customCSS classFlexible drop-zone slot styled as a primary-tinted dashed panel. Use .card-custom__title and .card-custom__body for its contents.
.card-tagsCSS classRow of .tag elements aligned to the trailing edge of the card.
.card-ratingCSS classStar rating slot. Holds .card-rating__stars (with five .card-rating__star children using --filled, --half, or no modifier) and a .card-rating__count review count label.
.card-chevronCSS classChevron-down button positioned at the bottom-trailing corner of an Expandable card. Rotates 180° when .card--expanded is added.
.card-select-indicatorCSS classSquare checkbox positioned at the top-trailing corner of a Selectable card. Fills with primary when .card--selected is added.
.card--no-shadowModifierRemove the drop shadow. Adds a neutral primary border in its place.
.card--strokeModifierRemove the drop shadow and apply a black (Figma border-black) border for maximum emphasis.
.card--expandableModifierMake the card render with a chevron at the bottom-trailing corner. Default state is collapsed (chevron points down).
.card--expandedStateRotates the chevron 180° to indicate the expanded state. Add via JS when the card is toggled.
.card--selectableModifierMake the card behave as a toggleable option. Renders a square checkbox at the top-trailing corner.
.card--selectedStateFills the checkbox indicator with the primary token and shows a white check. The card border stays neutral per Figma.
.card--disabledStateGreyed-out state. Disables pointer events and applies the Figma disabled tokens to background, border, text, and icon.

Card Grid

Cards work cleanly in a responsive grid using their natural width and CSS grid for the layout. The fixed 360px card width keeps every card the same size; flex-wrap is what makes them flow to the next row at narrower viewports.

First

A repeating layout works well for paginated content or a small dashboard.

Second

Mix effect styles within a grid for visual rhythm.

Third

The Stroke variant gives a more editorial feel in a quiet grid.

RTL Support

All card variants flip cleanly for Arabic. Icon, content, and footer mirror their alignment, and the Selectable indicator moves to the trailing (left) corner because of inset-inline-end.
