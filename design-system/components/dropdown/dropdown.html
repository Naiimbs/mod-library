Dropdown

Dropdowns let people pick one or several options from a list. Two sizes, three field variants, error and feedback states, single and multi select with checkboxes, and the library's signature press line that grows across the field's bottom edge when open. Ported from the DGA library's dga-dropdown component.

Live demo

Dropdown

Click the field to open the list. Single select closes on choice; multi select keeps the list open and joins the selections.

This live demo contains only a preview of functionality and styles available for this component. Changing a control re-renders the dropdown closed and clears the selection.

Props / Configuration

All available CSS classes for configuring dropdowns, mapped from the library's dga-dropdown API.

Class Type Library prop Description
.dropdown Base — Positioning container for the trigger button and the options list.
.dropdown--lg / --md Modifier size Field heights 40px / 32px; the list opens below the field accordingly.
.dropdown--lighter / --darker Modifier variant Borderless variants: lighter is transparent, darker sits on a gray-100 fill. Both regain their border on hover and open.
.dropdown--error / --readonly / --disabled State error, readonly, disabled Error recolors the border and press line; read-only and disabled mute the field and ignore interaction.
.dropdown--multi-select Modifier multi-select Options render 24px checkboxes; the trigger joins selections with commas.
.dropdown__btn [+ .open, .active] Element — The trigger. Open rotates the chevron and grows the bottom press line to full width; active (pressed) shows it at 50%.
.dropdown__label / __label-placeholder Element placeholder Adding --selection to the label shows it and hides the placeholder.
.dropdown__list / __list-group / __list-group-label Element option-list The floating listbox (max 376px, styled scrollbar) with optional grouped sections.
.dropdown__option [+ .selected, --checkbox] Element — Option row. Selected shows a trailing tick, or fills the leading checkbox in multi select.
.dropdown__feedback-icon--success|--error|--warning Element feedback Status icon inside the field with a soft tinted halo.

Default

Click the field to open it. Choosing an option fills the trigger label and shows a tick next to the selection.

Region

Variants

Lighter drops the border until interaction; darker sits on a gray fill. Both regain the default border when hovered or open.

Validation & States

Error outlines the field and recolors the press line; a feedback icon with a tinted halo can sit before the chevron. Read-only and disabled mute the field.

      Multi Select

      Options carry 24px checkboxes and stay open while choosing; the trigger joins the selections with commas.

      RTL Layout

      The field, chevron, and options mirror in right-to-left layouts.
