Second Nav Header

The Second Nav Header is a secondary navigation bar that appears above the primary navigation, offering additional controls or context-based information such as weather, date, time, and location, along with action buttons for quick access to features like zoom and microphone.

Live demo

Second Nav Header

Configure the secondary navigation header appearance.

Props

Prop Type Default Description
style 'Gray' | 'Primary' 'Gray' Visual style — Gray (neutral background) or Primary (green background)
rtl boolean false Right-to-left layout (Arabic text, reversed item/action order)
showContent boolean true Show the first content item (e.g. weather)
showItem2 boolean true Show the 2nd content item (date)
showItem3 boolean true Show the 3rd content item (time)
showItem4 boolean true Show the 4th content item (location)
showActions boolean true Show the action buttons group
showAction2 boolean true Show the zoom-in action button
showAction3 boolean true Show the zoom-out action button
showAction4 boolean true Show the mic/voice action button
showDivider boolean true Show the bottom border divider
