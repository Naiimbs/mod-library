Text Input

An input allows people to enter short, free form text data. If you need to collect more than one line of information, try a textarea.

Live demo

Text Input

A single-line text field for short form input like names, emails, and search queries.

Props

Prop Type Default Description
label string — Label text displayed above the input.
placeholder string — Placeholder text shown when the field is empty.
size 'md' | 'lg' 'lg' Input height — medium (32px) or large (40px).
type 'text' | 'number' | 'password' | 'email' | 'tel' 'text' HTML input type.
variant 'default' | 'lighter' | 'darker' 'default' Visual style variant controlling background color.
value string '' Current value of the input.
disabled boolean false Prevents user interaction.
readonly boolean false Makes the content non-editable but copyable.
error boolean false Applies error styling (red border).
required boolean false Marks the field as required (asterisk on label).
helper-text string — Descriptive hint text displayed below the field.
icon leading | trailing — Icon position inside the input field.
addon-type 'text' | 'dropdown' 'text' Prefix/suffix type — plain text or interactive dropdown with chevron.
addon-style 'solid' | 'subtle' 'solid' Prefix/suffix visual style — solid (gray bg) or subtle (transparent).

States

All interactive states — default, filled, disabled, read-only, and focus (click to see).
