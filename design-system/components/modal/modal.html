Modal

A focused dialog for messages, confirmations, and short tasks that need the user's attention. Composed of a header (featured icon + close), a body (title + description + optional swap content), and an actions row. Supports desktop (600px) and mobile (320px) widths, leading/center title alignment, inline or stacked actions, and full RTL. Modeled on Figma frames 30150:55001 (Modal), 30150:55018 (Header), 30150:55083 (Body), 30150:55043 (Actions), 30150:55096 (Swap placeholder).

Props / Configuration

All available CSS classes and JS hooks for composing and controlling modals.

Class / Attribute Type Description
.modal-backdropCSS classFixed full-screen overlay that centers the modal and dims the page. Add .is-open to show it.
.modalCSS classThe dialog container. White bg, 8px radius, shadow-3xl, 24px padding. 600px wide by default.
.modal--mobileModifierNarrows the dialog to 320px (mobile layout).
.modal--centerModifierCenters the featured icon and title.
.modal-header / .modal-header__topSlotHeader stack: the top row holds the featured icon (leading) and close button (trailing); the title sits below.
.modal-iconSlotCircular featured icon (40px). Holds an icon-font glyph.
.modal-closeSlotClose (X) button. Pair with data-modal-close to wire dismissal.
.modal-titleSlotTitle — 18/28 semibold, text-display #1F2A37.
.modal-body / .modal-descriptionSlotBody wrapper + description copy — 14/20 regular, text-primary-paragraph #384250.
.modal-customSlotDashed primary swap-content placeholder for composing custom modal content.
.modal-actionsSlotAction row. Inline + trailing-aligned by default.
.modal-actions--stackModifierStacks the buttons vertically, full-width (mobile pattern).
.modal-actions--fillModifierEach button stretches to fill the row equally.
data-modal-open="ID"JS hookOn any trigger element — opens the .modal-backdrop with that id.
data-modal-closeJS hookOn any element inside a backdrop — closes the modal. Backdrop click and ESC also close.

RTL Support

Arabic and other right-to-left layouts mirror the modal: the featured icon moves to the trailing (right) edge, the close button to the left, and the title + actions align from the right.
