Tabs

A tablist is a group of headers that lets people navigate between different views of related information without going to different pages. Available in 3 sizes with icon, divider, flush, and RTL support.

Tabs

Tabs organize content into separate views where only one view is visible at a time. Selecting a tab reveals its associated content.

Props / Configuration

All available CSS classes and HTML attributes for configuring tab components.

Class / Attribute Type Default Description
.tab-list CSS class Required Container element for the tab list. Provides flex layout and positioning.
.tab-list__divider CSS class — Full-width bottom line behind tabs. Provides a visual baseline.
.tab-list__tabs CSS class Required Inner wrapper that holds the individual tab items.
.tab-item CSS class Required Individual tab element. Defaults to medium size.
.tab-item--sm CSS class — Small tab size (8px/12px padding).
.tab-item--lg CSS class — Large tab size (16px padding all sides).
.tab-list--sm CSS class — Applies small size to all child tab items.
.tab-list--lg CSS class — Applies large size to all child tab items.
.tab-list--flush CSS class — Flush variant. Removes container padding so tabs sit edge-to-edge.
.active CSS class — Marks the currently selected tab. Shows green indicator bar and bold text.
disabled HTML attr false Disables a tab. Grays out text and icon, prevents interaction.
role="tablist" HTML attr — ARIA role on the tab-list container.
role="tab" HTML attr — ARIA role on each tab-item for accessibility.
aria-selected HTML attr — Set to "true" on the active tab, "false" on others.

Tab Sizes

Three size options for different content density. Medium is the default, Small for compact layouts, and Large for prominent navigation.

Without Icons

Tabs can be used without icons for a simpler, text-only appearance. Works with all sizes.

Tab States

Interactive states provide visual feedback. The active tab shows a green indicator bar and bold text. Disabled tabs are grayed out and non-interactive. Hover and pressed states are handled by CSS.

RTL Support

Tabs in right-to-left layout for Arabic and other RTL languages. Tab order and icon positions are mirrored automatically.
