Footer

A footer serves several functions, including providing navigation, housing links to important information, offering contact details, and sometimes integrating social media icons and accessibility tools. Supports Default and Dark Green backgrounds, LTR/RTL layouts, and responsive breakpoints.

Live demo

Footer

Configure the footer appearance and sections.

Props

Prop Type Default Description
backgroundColor 'Default' | 'Dark green' 'Default' Background style — Default (neutral gray #F3F4F6) or Dark green (#166A45)
rtl boolean false Right-to-left layout (Arabic text, reversed content order)
breakpoint '600+' | '<600' '600+' Responsive breakpoint — desktop (600+) or mobile (<600)
navLinks boolean true Show the navigation link groups section
