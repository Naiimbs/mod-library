Rating

Ratings collect or display a score out of five stars. Three sizes, half-star precision, a hover preview, a brand-colored variant, and a read-only display mode. Ported from the DGA library's dga-rating component; stars come from the DGA icon font.

Live demo

Rating

Click a star to rate it. Clicking the first half of a star gives a half rating; hovering previews the score.

This live demo contains only a preview of functionality and styles available for this component. Changing a control resets the value to 3.5.

Props / Configuration

All available CSS classes and data attributes, mapped from the library's dga-rating API.

Class / Attribute Type Library prop Description
.rating Base — Declarative: set data-max and data-value and the page script builds the star buttons.
.rating--sm|--md|--lg Modifier size Star sizes 24 / 32 / 48px.
.rating--brand Modifier color Saudi green stars instead of the default gold.
.rating--readonly Modifier readonly Display-only: no hover preview, clicks ignored.
.rating__star + data-fill="none|half|full" Element rating A star button: stroke base with a solid overlay clipped to 0 / 50% / 100% width.
data-value="3.5" Attribute rating The committed score, in half-star steps.

Sizes

Three star sizes; the value here is 3.5 to show a half fill.

Colors & Read-only

Gold is the default; the brand variant uses Saudi green. Read-only ratings display a fixed score.

RTL Layout

Stars fill from the right and half-star clicks use the star's right half.
