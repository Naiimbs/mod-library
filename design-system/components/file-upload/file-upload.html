File Upload

Lets users select and upload files from their device. They drop or browse to a designated zone, review their selections, and watch upload progress before getting a success (or error) confirmation. Supports single or multiple files, a disabled state, and full RTL. Modeled on Figma frames 30146:37007 (Multiple), 30146:37020 (Single), and the nested _File and _Drop Zone components.

Live demo

File Upload

This demo really works — drop a file or click the browse button to add one, watch the simulated progress, then remove it.

Single mode keeps only the most recent file; multiple mode appends each new selection. The disabled state blocks all interaction.

Props / Configuration

Classes and JS hooks for the file upload component.

Class / Attribute Type Description
.file-uploadContainerWraps the drop zone and the file list. Add --single or --rtl.
.file-upload__dropzoneSlotThe drop area with the upload icon, title, browse button, and helper text. States: .is-dragover, .is-disabled.
.file-upload__browse-btnControlThe browse action — a real .btn (Figma _Drop Zone "Button" / action-name).
.file-upload__dz-hintSlotThe helper text (Figma "Show Helper Text") — max size + supported formats.
.file-upload__inputControlThe visually-hidden native <input type="file">. Set multiple / accept on it.
.file-upload__fileItemA file row: type icon, name + meta, progress or status, and a remove button. States: --success, --error.
data-file-uploadJS hookOn the container — activates drag/drop, browse, progress, and remove. Add data-multiple for multi-file.
