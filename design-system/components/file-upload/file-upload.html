File Upload

Lets users select and upload files from their device. A dashed drop area with an upload icon, instruction text, supported-formats hint, and a browse button; selected files appear below as flat rows with a status icon, the file name, and a remove action. Errors wrap the row in red and attach a message strip. Rebuilt to match the DGA library's dga-file-upload anatomy exactly.

Live demo

File Upload

This demo really works — drop a file or click the browse button to add one, watch the simulated upload, then remove it.

Single mode keeps only the most recent file; multiple mode appends each new selection. The disabled state blocks all interaction.

Props / Configuration

All available CSS classes, mapped from the library's dga-file-upload API.

Class Type Library prop Description
.file-upload Base — Column container (max-width 334px) holding the drop area and the files list.
.file-upload--drag-over State drag-state Brand tint with a green dashed border while a file hovers the area.
.file-upload--disabled State disabled Gray fill, muted text, all interaction blocked.
.file-upload__drop-area Element — A <label> for the hidden input: dashed SVG border, upload icon, instructions, formats hint, and the browse button.
.file-upload__instructions / __formats Element title, file-types-text 16px medium instruction line and the 12px supported-formats hint.
.file-upload__input Element accept, multiple The visually-hidden native <input type="file">.
.file-upload__files-list / __file-item Element files Flat gray rows: status slot, file name, and a small close button.
.file-upload__file-status--complete|--error / __spinner Element upload-status Green check when complete, red icon on error, tiny spinner while uploading.
.file-upload__file-item--error + __file-item-msg Element error-message Red-bordered wrapper: the file row on top, the error message strip below.

Drop Area

Default, drag-over, and disabled. The dashed border is an SVG stroke (12 / 6.5 dashes), swapping from gray to Saudi green while a file hovers.

File Items

Uploading shows a tiny spinner; complete shows the green check; an error wraps the row with a red border and attaches the message strip below.
