Notification

Notifications are prominent UI elements used to convey important information or alerts to users. They typically appear at the top of a webpage or application screen, drawing immediate attention to their content.

Live demo

Notification

Configure the notification appearance and features.

Props

Prop Type Default Description
variant 'critical' | 'warning' | 'success' | 'info' | 'neutral' --- Visual style variant of the notification.
lead-text string --- Bold heading text displayed before the content.
content string --- Helper/body text of the notification.
icon boolean true Show or hide the feedback icon.
link boolean false Show a text link in the actions area.
text-link string --- Text content for the link.
button boolean false Show an action button.
dismissable boolean false Show a close/dismiss button.

Variants

Five style variants for different severity levels: critical, warning, success, info, and neutral.
