Skeleton

Skeletons hold the layout while content loads. Four primitives (line, rectangle, circle, square) with two gradient directions and a 2-second opacity pulse, composable into loading patterns for cards, lists, and profiles. Ported from the DGA library's dga-skeleton family.

Props / Configuration

All available CSS classes, mapped from the library's dga-line-skeleton, dga-rectangle-skeleton, dga-circle-skeleton, and dga-square-skeleton APIs.

Class Type Library prop Description
.skeleton Base — Gradient placeholder with the 2s opacity pulse. Combine with a shape modifier.
.skeleton--type2 Modifier type Reverses the gradient direction (dark-to-light). Default is light-to-dark.
.skeleton--line + --sm|--lg Shape size Text-line placeholder, 277px wide, 14px or 22px tall, 8px radius.
.skeleton--rectangle + --sm|--md|--lg [+ --short] Shape size, width Block placeholder, 320px wide × 24/32/40px tall; --short shrinks to button width (59/75/90px).
.skeleton--circle Shape width Avatar/icon placeholder. Size with inline width/height (default 48px).
.skeleton--square [+ --rounded] Shape width, radius Image/chart placeholder. Size with inline width/height (default 80px).
.skeleton-pattern* Layout — Composition wrappers: __wrapper (24px column), __lines (12px column), __row/__col (media + text), __first/ __last (start-aligned rows).

Shapes

The four primitives. Lines hold text, rectangles hold fields and buttons, circles hold avatars, squares hold imagery.

Rectangle Sizes

Three heights at full width, and the short variant sized for buttons.

Gradient Directions

Type 1 runs light-to-dark; type 2 reverses it. Alternate directions between adjacent placeholders for a subtler texture.

Patterns

Primitives composed into common loading layouts: a profile row, a media card, and an icon list.

Reduced Motion

When the user prefers reduced motion, the pulse stops and skeletons render as static placeholders. No extra classes needed.
