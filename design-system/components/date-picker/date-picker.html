Date Picker

A Date Picker enables users to select dates via a pop-up calendar dropdown. It is triggered by clicking a calendar icon or input field and is used in forms for scheduling events, booking appointments, or entering birthdates.

Date Picker

A Date Picker enables users to select dates via a pop-up calendar dropdown for scheduling, booking, or entering dates.

This live demo contains only a preview of functionality and styles available for this component.

Props / Configuration

All available CSS classes and HTML attributes for configuring date picker components.

Component Props

Boolean props from the <dga-datepicker> library component. These control which features are enabled.

Prop Type Default Description
input-field boolean — Shows the date input field above the calendar panel.
range boolean — Enables date range selection with start and end dates.
qick-options boolean — Shows the quick-option presets sidebar (Today, This week, etc.).
submit-button boolean — Shows the footer with Clear and Apply action buttons.
dual-month-view boolean — Displays two calendar months side by side.
RTL boolean false Enables right-to-left layout for Arabic and other RTL languages.
initial-date Date — Sets the initial date displayed in the calendar (JS only).
value object — The selected date value object (JS only).

Callbacks

Callback Type Default Description
onSubmit function — Fired when the user confirms a date selection (JS only).
onCancel function — Fired when the user cancels the date picker (JS only).

CSS Classes

Design system CSS classes used to build and style date picker sub-components.

Class / Attribute Type Default Description
.date-field CSS class Required Base container for the date input field.
.date-field__label CSS class — Label text displayed above the input.
.date-field__label--required CSS class — Adds a required asterisk (*) indicator to the label.
.date-field__wrapper CSS class — Wrapper containing the input and calendar icon.
.date-field__input CSS class — The text input element for the date value.
.date-field__input--error CSS class — Error state with red border color.
.date-field__input--active CSS class — Active/focused state when calendar is open.
.date-field__icon CSS class — Calendar icon container inside the input.
.date-field__helper CSS class — Helper text displayed below the field.
.date-field__helper--error CSS class — Error message styling with red text and icon.
.date-field--disabled CSS class — Disabled state for the entire field container.
.date-picker__panel CSS class — Calendar dropdown panel containing the grid.
.date-picker__panel--static CSS class — Always-visible calendar (no open/close toggle).
.date-cell CSS class Required Individual day cell in the calendar grid.
.date-cell--today CSS class — Today's date highlight with green border.
.date-cell--selected CSS class — Selected date with green fill.
.date-cell--disabled CSS class — Non-selectable date cell.
.date-cell--outside CSS class — Day from an adjacent month (dimmed text).
.date-cell--range-start CSS class — Start date of a selected range.
.date-cell--range-mid CSS class — Dates within the selected range (light green).
.date-cell--range-end CSS class — End date of a selected range.
.date-picker--with-presets CSS class — Layout with quick-option presets sidebar.
.date-picker--attached CSS class — Calendar visually attached below the input field.
.date-picker__dual-fields CSS class — Side-by-side start and end date fields.
.is-open CSS class — Opens the calendar panel or year dropdown.
readonly HTML attr — Prevents manual text entry in the date field.
disabled HTML attr false Disables the date field and prevents interaction.

The input field that triggers the calendar panel. Includes a trailing calendar icon. Shown in empty, filled, and required states.

Error and disabled field states. Error shows a red border with a validation message below. Disabled grays out the entire field and prevents interaction.
