Buttons

Interactive button components following DGA design guidelines. Includes 6 variants, 3 sizes, multiple states, and modifiers for destructive actions, dark backgrounds, loading indicators, and floating action buttons.

Button Variants

The six core button styles. Neutral for general actions, Primary for the main call-to-action, Secondary Solid and Outline for supporting actions, Subtle for low-emphasis actions, and Transparent for inline text-level actions.

Button Sizes

Three size options to fit different contexts. Large (40px) is the default, Medium (32px) for denser layouts, and Small (24px) for compact or inline usage.

Button States

Interactive states that provide visual feedback during user interaction. Default, Hover, Pressed, Selected, and Disabled states ensure clear communication of button status.

Selected State

Toggle-style buttons with a persistent selected appearance using the aria-pressed attribute. Shown across all variants, including destructive selected states.

Destructive Selected

Destructive Variants

Red-tinted variants for actions that delete data or are irreversible. Available across all six button styles to match the surrounding UI context.

Buttons with Icons (SVG)

Buttons paired with inline SVG icons for enhanced visual recognition. Icons can be placed before or after the label. Icon-only buttons provide compact actions across all three sizes.

Icon Only

Buttons with Icon Font

Using the DGA icon font system instead of inline SVGs. Apply the icon font class directly to a span element inside the button. Supports all sizes and icon-only variants.

Sizes
Icon Only

On-Color Variants

Buttons designed for use on dark or colored backgrounds. These variants use white and semi-transparent fills to maintain contrast and readability on the primary brand color.

Destructive On-Color Variants

Destructive action buttons adapted for dark backgrounds. Red tones are adjusted for visibility against the primary brand color.

Loading State

An animated spinner replaces the button label to indicate a pending operation. The button becomes non-interactive during loading to prevent duplicate submissions.

Floating Action Button (FAB)

Elevated, pill-shaped buttons for primary screen-level actions. Available in Large (56px) and Small (40px) sizes, with both labeled and icon-only variants.

Button Group

Adjacent buttons joined into a single visual unit. Border radii are removed on interior edges to create a seamless segmented control appearance.

RTL Support

Right-to-left layout support for Arabic and other RTL languages. Icon placement and button group ordering are automatically mirrored.
