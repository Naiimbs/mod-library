Filters

A filtration component that helps users refine content by selecting criteria. A neutral trigger button opens a floating panel of filter blocks (search, checkbox lists with show more, chips, ranges); applied filters appear as primary buttons with a remove action. Rebuilt to match the DGA library's dga-filteration anatomy, composed from the design-system button, checkbox, chip, search box, and text input components.

Filters

This demo really works — open the panel, search and tick options, apply them, then remove the applied filters one by one or clear all.

Props / Configuration

All available CSS classes, mapped from the library's dga-filteration API.

Class Type Library prop Description
.filteration Base — Column container: trigger + applied-filters row, with the floating panel anchored to it.
Trigger button Composition button-label A design-system .btn.btn-neutral (large) with a leading filter icon and a trailing chevron, both white.
.filteration__selected-filters Element selected-filters Applied filters as primary .btn.btn-primary buttons with a trailing × that removes them. New entries fade in.
.filteration__panel [+ .is-open] Element is-filter-panel-open Floating 320px panel: 8px radius, gray-300 border, soft shadow, slide-down entrance, 75vh scroll. On mobile it centers as a fixed sheet.
.filteration__block / __block-title Element filter-blocks One filter group: 14px semibold title, gray-50 hover, 20px start indent, divider below.
.filteration__block-content--checkbox|--radio|--chips|--select Modifier block.type Layout per block type; checkbox blocks show 3 options collapsed.
.filteration__search Element — A design-system search box that filters the block's options as you type.
.filteration__block-actions Element — "Show N more / Show less" — a transparent button with a chevron, shown when a checkbox block has more than 5 options.
.filteration__range Element block.type="range" Two 125px text inputs joined by a dash.
.filteration__actions Element — Apply filters (neutral) + Clear filters (secondary outline), end-aligned, min-width 120px, above a gray-200 top border.
